# NÜA Café — site vitrine

Site statique (HTML, CSS, JavaScript), sans installation. Ouvrez `index.html` dans un navigateur.

## Infos utilisées (tirées d'Instagram @nuacafe.bko et TikTok @nuacafe.com)
- Hamdallaye ACI 2000, Bamako — ouvert de 8h à 20h
- Téléphone : +223 70 74 86 74 (le bouton WhatsApp suppose que ce numéro est sur WhatsApp : à confirmer)
- Itinéraire : https://maps.app.goo.gl/NPAirMPcf62PtJgh7

Le badge « Ouvert maintenant / Fermé » se calcule automatiquement à l'heure de Bamako.

## Remplacer les photos
Les photos sont des illustrations libres de droits (Unsplash). Pour mettre les vraies photos du café,
remplacez les fichiers dans `images/` **en gardant le même nom** :

| Fichier | Où |
| --- | --- |
| `hero.jpg` | Grande photo d'accueil |
| `concept.jpg` | Section « Le café » |
| `sig-iced-latte.jpg`, `sig-matcha.jpg`, `sig-pancakes.jpg`, `sig-croissant.jpg` | Cartes « Signatures » |
| `g1.jpg` … `g8.jpg` | Mosaïque « Ambiance » |
| `quote.jpg` | Fond de la citation « Bad day ? Iced latte. » |

## Mise en ligne
Hébergé sur Vercel, relié au dépôt GitHub : chaque fichier modifié sur GitHub remet le site à jour automatiquement.
Le dossier `_ressources/` (captures Instagram/TikTok) n'est pas publié.
